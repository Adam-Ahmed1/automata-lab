# Automata Lab

**Status:** ongoing independent project.

[Open the workspace](https://doma990.github.io/projects/automata-lab/demo/) · [Project overview](https://doma990.github.io/projects/automata-lab/)
DFA and NFA functionality is available now. GNFA support is planned.

NFAs support multiple transition targets, ε-transitions, active-state traces, empty-string tests, and conversion to DFA. Machines can be saved in the browser or imported and exported as JSON.

Run `npm start` to open the workspace at `http://127.0.0.1:4175`. Run `npm test` for model and integration checks. The GitHub Pages workflow publishes `dist` when changes reach `main`.
